# Meeva

Software company headquarters. Live products in the marketplace. Upcoming work on a shareable coming-soon page.

Products are listed in `src/config/site.ts` and do not have to live in this repo.

## Quick start

```bash
cd meeva
pnpm install
pnpm dev
```

Open [http://localhost:4400](http://localhost:4400).

| Path | Page |
|------|------|
| `/` | Company |
| `/marketplace` | Live store |
| `/soon` | Coming soon (share this) |
