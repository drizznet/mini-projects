# Meeva

**drizz.dev** lives at `/` — freelance software developer, open to work.

Meeva, the software company, lives at `/meeva`. Live products in the marketplace. Upcoming work on a shareable coming-soon page.

Products are listed in `src/config/site.ts` and do not have to live in this repo. Portfolio copy is in `src/config/portfolio.ts`.

## Quick start

```bash
cd meeva
pnpm install
pnpm dev
```

Open [http://localhost:4400](http://localhost:4400). If that port is taken: `pnpm dev --port 4500`.

| Path | Page |
|------|------|
| `/` | Drizz — portfolio |
| `/meeva` | Meeva — company |
| `/marketplace` | Live store |
| `/soon` | Coming soon (share this) |
