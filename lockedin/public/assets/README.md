# lockIn assets

Drop licensed brand files here. The app keeps the current chevron mark and Inter
until these land.

## Mark — `brand/`

| File | Use |
|------|-----|
| `brand/mark.svg` | App icon / lockup (square, ~32–64 viewBox) |
| `brand/mark.png` | Raster fallback, 512×512 |
| `brand/wordmark.svg` | Optional full wordmark if the type is custom |

## Fonts — `fonts/`

Only if lockIn uses a face we cannot load from Google/Fontsource. `.woff2`.

## Product stills — `product/`

Marketing or store screenshots, ~1600px wide `.jpg` or `.webp`.
