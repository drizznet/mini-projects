# lockIn SEO Terms Glossary

## SEO

**Meaning**  
Making a website easier for search engines and people to find.

**lockIn example**  
Helping someone searching “personal focus planner” discover lockIn.

## Metadata

**Meaning**  
Information about a page that appears in the browser tab and search results.

**lockIn example**  
Page title: `lockIn — Personal Focus System`.

## Canonical URL

**Meaning**  
The official URL for a page when multiple URLs show similar content.

**lockIn example**  
Tells Google that `https://lockin.app/` is the official landing page.

## Open Graph

**Meaning**  
The title, description, and image shown when someone shares a page on Slack, WhatsApp, LinkedIn, or Facebook.

**lockIn example**  
A lockIn preview card with the logo and product headline.

## Twitter/X Card

**Meaning**  
Sharing information specifically for X/Twitter.

**lockIn example**  
Controls how a lockIn link appears in a post.

## Sitemap

**Meaning**  
A list of public pages that tells search engines what pages exist.

**lockIn example**  
A file listing `/` and future public pages.

## Robots File

**Meaning**  
Instructions telling search engines which pages they may crawl.

**lockIn example**  
Allow `/`, but hide `/dashboard` and `/settings`.

## `noindex`

**Meaning**  
An instruction telling search engines not to put a page in search results.

**lockIn example**  
Keep a user’s dashboard out of Google.

## Structured Data

**Meaning**  
Extra machine-readable information describing the page.

**lockIn example**  
Tells Google that lockIn is a software application.

## JSON-LD

**Meaning**  
The common format used to write structured data.

**lockIn example**  
A small JSON block describing lockIn.

## Open Graph Image

**Meaning**  
The preview image attached to a shared link.

**lockIn example**  
A branded lockIn image with “Protect your attention”.

## Web Manifest

**Meaning**  
Information that helps browsers treat a site like an installable app.

**lockIn example**  
App name, icon, theme color, and launch URL.

## Core Web Vitals

**Meaning**  
Measurements of loading speed, visual stability, and responsiveness.

**lockIn example**  
How quickly the lockIn landing page appears and responds.

## Server-rendered HTML

**Meaning**  
HTML generated before it reaches the browser.

**lockIn example**  
Search engines can read the landing-page content immediately.

## Search Intent

**Meaning**  
What someone is trying to accomplish with a search.

**lockIn example**  
Someone looking for a tool to plan and protect focused work.

## Example: Sharing the lockIn Landing Page

Someone shares:

`https://lockin.app/`

- Open Graph metadata controls the preview card.
- The canonical URL tells Google this is the official page.
- The sitemap helps Google discover the page.
- Structured data helps Google understand what lockIn is.
